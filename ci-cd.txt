CD - entrega continua do sistema nos ambientes. CD tbm é chamado de continuous deployment por isso


------------------

npm ci:
- comando clean-install: comando do npm que pode substituir o npm i. limpa node modules antes do install e usa a versao do package.lock pra instalar dependencia.

    - o package.lock deixa travado a versao, o package.json pode instalar versoes diferentes
     ex: "nome-lib": "^7.2.2" significa que o `npm i`  pode instalar versoes 7.3.0 ou 7.4, qualquer versao atualizada mantenaod apenas a versao major 7.

o npm ci vai instalar exatamante 7.2.2

os scripts de teste dependem do que ta na variavel .env.test

no arquivo ci.yml, o comando "run: env > .env.test" usa o comando linux "env > .env.test"
- o comando "env > .env.test" cria um clone de .env com o nome .env.test
